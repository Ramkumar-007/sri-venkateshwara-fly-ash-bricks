# sri-venkateshwara-fly-ash-bricks-

Static website for Sri Venkateshwara Fly Ash Bricks in Tharalkuttai, Salem.

## Vercel deployment

- Framework preset: **Other**
- Root directory: repository root (`.`)
- Build command: leave empty
- Output directory: `.`

The site is served from `index.html`; its CSS, JavaScript, and images are local files. No build step or runtime dependencies are required.
